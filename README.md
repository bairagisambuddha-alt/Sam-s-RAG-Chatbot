# Sam-s-RAG-Chatbot
This is a Rag Chatbot to answer question based on documents provided like java.pdf and webscraping.txt.
----STEP BY STEP GUIDE TO RUN THIS PRJOECT----
1)Create your python environment and install required libraries(available in requirements.txt)

2)To run main.py use the command:
  -->cd backend
  -->uvicorn main:app --reload

3)to run app.py use command
  --> streamlit run app.py
